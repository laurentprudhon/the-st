# German Atari ST magazine landscape, 1985–1996 — and where the scans live

STATUS: complete (v1) — probed 2026-11-15 in one pass (~55 HTTP probes: HTML, IA `advancedsearch`/`metadata`, PDF range probes, de.wikipedia API). All issues/„issues" figures below are either **counted** (I fetched the page/index and counted links or API hits) or **stated** (quoted from Wikipedia / the site itself) or **unverified** (my own prior, not confirmed here — flagged inline).

Method notes: metadata, index pages and file listings only. No issue was downloaded; nothing copyrighted was written to disk. Two IA `_djvu.txt` files and two Atarimania PDFs were read **in memory** (streamed, discarded) purely to establish whether a text layer / OCR exists and what the score vocabulary looks like; only short fragments were inspected, none stored.

## 3. The four special questions

**(a) Does the ST-Computer archive serve one page per URL or one PDF per issue?**
Neither in the scan sense. **stcarchiv.de serves one HTML page per *article*, not per page-scan and not a PDF**: `/{mag}/{YYYY}/{issue}` is an issue index listing every article with its printed page number, and `/{mag}/{YYYY}/{issue}/{slug}` is a full transcribed article body. There is no PDF and no page image anywhere in that site (0 pdf/download hrefs on the issue pages I parsed). If you want *scans*, one-PDF-per-issue comes from **Atarimania** (`/mags/pdf/ST-Computer-YYYY-MM.pdf`) and **IA** (`st-computer_YYYY-MM`, PDF + jp2 + djvu.txt).

**(b) Do German items on IA carry `djvu.txt`?**
**Yes, for the scanned-and-derived items**: `Atari-Magazin-93-05` → `_djvu.txt` + `_text.pdf` + `_abbyy.gz`; `st-computer_1990-05` → `_djvu.txt` + `_djvu.xml` + `_hocr.html` + `_hocr_searchtext.txt.gz` + `_chocr.html.gz`; `st_magazin_1988-05` same set; `68000er8702` → `_djvu.txt` (602 KB, real German OCR, mediocre quality). **But not universally**: the `ASM.N*` uploads are bare **JPEG page sets** (`…_400dpi_24pp/…_NNN.jpg`, selected pages only, 29 files, no PDF, no OCR), so ASM — the German magazine with the heaviest ST review volume — would need OCR run from scratch.

**(c) Is there an existing index of German ST reviews („Test: <game>" with issue + page)?**
**Yes — stcarchiv.de is exactly that index, and it is the single most valuable German artefact for this catalogue.** Every issue page is an article-level table of contents with printed page numbers, and review articles are titled by game (e.g. `/st-magazin/1991/05/enchanted-land`, `/st-magazin/1991/05/test-drive-ii`), each ending in the printed score block (ST-Magazin: `Note: 6 von 6` + `Hersteller: Thalion` + `Preis: 64.95 DM`). It covers ST-Computer, ST-Magazin, TOS, Atari Magazin, Atari Inside and Happy Computer.
Second-best, and broader but much shallower: **kultpower.de**'s catalogue (10,306 articles) is queryable by game name and returns magazine + issue + page (`suche.php?aktion=suchen&suche=Populous` → 12 hits across Powerplay/Amiga Joker/PC Joker/Videogames), but it holds **no dedicated ST title** and the hits carry no platform field, so „Populous" hits have to be opened to learn whether the reviewed version was Amiga or ST.
Gap: **no index records the reviewed platform for German magazines**, and none exists for **68000er** (1987–88), whose 15 issues are on IA as OCR but have no article-level index anywhere.

**(d) Which German titles are DEDICATED ST magazines versus shared Atari/Amiga coverage?**
**Dedicated ST** (buy these first — every review in them is an ST review): **ST-Computer** (1986–2004, the longest-running ST magazine in the world), **ST-Magazin / 68000er** from issue 4/88 to 8/93, **TOS** (1990–93), **Atari Inside** (1994–96, Jaguar-era).
**Shared**: **68000er** before 4/88 („Magazin für Amiga, Macintosh und Atari ST" — Amiga and ST reviews in the same issue), **Atari Magazin** (Rätz; „für alle Ataris", 8-bit + ST until ~1992, then XL/XE-only — so only its 1987–1992 issues carry ST reviews), **Happy Computer** (multi-system), **ASM** (multi-system), **Power Play** (multi-system), **Video Games** (consoles; ST effectively absent), **Computer Persönlich** (multi-system).
**Excluded, Amiga-only**: **Amiga Joker** (1989–96), Amiga Juggler — they reviewed no ST software, and their scores are the most common false positive when German Amiga ratings get mistaken for ST ratings.

## 4. Best German OCR starting point

Start with **stcarchiv.de**, and treat it as a *text* corpus rather than a scan corpus: it is the only German archive where the article text, the printed page number, the game title and the score block already exist as machine-readable HTML, across 223 ST-Computer issues, 66 ST-Magazin issues, 39 TOS issues and 24 Atari-Magazin issues — i.e. the entire dedicated-ST review core with no OCR step at all, and with the score vocabulary of two different magazines (0–10 with sub-scores for ST-Computer; „Note X von 6" plus publisher and DM price for ST-Magazin) recoverable by regex from the article tail. Its weakness is that it is a transcription, so it inherits someone else's decisions (the 0–10 sub-scores do not appear in the two print issues whose OCR I could check — print shows only a graphical „Wertung:" block), and it must be spot-checked against scans before any score is published as fact. For the scans themselves the correct pairing is **TOS from Atarimania** (38 of ~39 issues, and those PDFs actually carry a text layer) plus **ST-Computer 1986–1991 from the Internet Archive** (`st-computer_*` items, all with `_djvu.txt`, plus the `st-computer-1988-12` year pack that fills IA's 1988 hole). Do **not** start from kultpower (right catalogue, wrong platform) and do **not** budget for ASM unless you accept raw OCR: its IA uploads are partial JPEG page sets with no text layer, and ASM is the one German magazine where ST review volume is high but machine-readable text is zero.
